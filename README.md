<div align="center">
  <h2>Premise</h2>
</div>

**AfterCast AI** is a 3.5 year old B2B SaaS startup in Lagos, Nigeria & London, UK. They provide AI-powered demand and post-purchase forecasting, as well as inventory analytics for mid-size retail brands. They just closed Series A after landing 2 big retail clients (LuxeMart, UK and ShopLeft, Nigeria). They grew fast from 8 to 30 staff.

The startup is a zero-cloud organization with no central cloud infrastructure. Operations employ a wide variation of software and hardware tools from different providers using different accounts set up with staff private credentials. On-prem servers, software from multiple providers, personal devices, uncoordinated device and data security controls, and shadow-IT, constitute current business infrastructure.

<div align="center">
  <h2>Project Objectives</h2>
</div>

This project aims to provide the maturing startup with a fresh enterprise cloud environment using AWS and migrate data-handling business operations into it. Apart from supporting business activities, this virtual private cloud environment would be provisioned with a high priority placed on ensuring data security and multi-regional compliance \[EU's **GDPR** & Nigeria's **NDPA (2023)**\].
