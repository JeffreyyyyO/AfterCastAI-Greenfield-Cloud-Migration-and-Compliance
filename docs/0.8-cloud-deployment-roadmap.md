## 1. Architectural Decisions

### 1.1 Organizational Unit (OU) Hierarchy

AWS Organizations and Organizational Units (OUs) cost $0.00. The roadmap deploys all 6 canonical OUs and places the 5 live accounts into their active OUs. The remaining OUs are governed by SCPs as architectural guardrails:

- **Root (`o-xxxxxxxxxx`):** Holds `aftercast-root` (`yourname+aftercast-root@gmail.com` — Management Account).
- **`Security` OU:** Holds `aftercast-logarchive` (`yourname+aftercast-logarchive@gmail.com`) and `aftercast-audit` (`yourname+aftercast-audit@gmail.com`). This OU also hosts the isolated Forensics VPC in Section 8.4 and aggregated security tooling (GuardDuty, Macie, Security Hub).
- **`Workloads-Prod` OU:** Holds `aftercast-prod` (`yourname+aftercast-prod@gmail.com`) — hosts the production Hub / Tiered VPCs, KMS keys, S3 Restricted-PII buckets, Lake Formation, and Aurora / Fargate workloads.
- **`Workloads-Dev` OU:** Holds `aftercast-dev` (`yourname+aftercast-dev@gmail.com`) — locked to `eu-west-1` with anonymized / synthetic test data only.
- **`Infrastructure`, `Sandbox`, and `Highly-Restricted-PII` OUs:** Created via Terraform and attached to strict SCPs (for example `Deny-All-Outside-EU`, `Require-PII-Tags-on-Create`). Account count remains strictly at 5.

### 1.2 Cost Model — 3-Tier Cost Guardrail

Test-environment cost with gating is $0 to $3 per month for most work. Production steady-state cost is $850 to $1,450 per month as in the Business Case. Test-environment cost and production cost are distinct.

**Tier 1 — Control Plane Definitions, $0.00 for the definition, Free Tier / pennies for use:**
AWS Organizations, OUs, SCPs, Tag Policies, IAM Identity Center (30 users, 6 groups, Permission Sets, ABAC attributes), IAM Roles / Policies, Permission Boundaries, GitHub OIDC, S3 Access Points, VPCs, Subnets, Route Tables, Security Groups, S3 Gateway Endpoints, DynamoDB Gateway Endpoints, and Lambda / Step Function definitions. The definitions are $0.00. Invocations, storage, and requests are Free Tier / pennies. A VPC itself is $0.00. A NAT Gateway, an Interface Endpoint, or data transfer inside that VPC is not $0.00.

**Tier 2 — Free Tier / Pennies, $0.00 to $3.00 per month for test-environment use:**
S3 buckets (with Versioning, Object Lock, and Lifecycle rules), DynamoDB On-Demand tables (`consent-ledger`, `dsr-requests`, `terraform-state-lock`), API Gateway + Cognito (`careers.aftercast.ai`), CloudWatch Logs, EventBridge, and SNS. These are Free Tier / pennies. S3 has storage + requests. DynamoDB has storage + reads / writes beyond Free Tier. API Gateway has requests beyond Free Tier.

- **KMS Customer Managed Keys:** $1 per key per month. Deletion requires a 7 to 30 day waiting period. A key remains in pending deletion for 7 to 30 days, and payment continues for that period. The roadmap uses 3 CMKs at $3 per month in the test environment, retained until Phase 10 evidence is complete.
- **GuardDuty:** 30-day AWS Free Trial, then paid.
- **Macie:** 30-day AWS Free Trial, then paid.
- **Security Hub:** 30-day AWS Free Trial, then paid.
- **WorkMail:** 30-day trial for up to 25 users, then paid per user per month.
- **Secrets Manager:** No free trial. $0.40 per secret per month + API calls.

**Tier 3 — High-Cost Hourly Resources, Gated by `var.enable_expensive_resources = false`:**
Paid hourly infrastructure is written in full production Terraform so it passes `terraform validate`, `tfsec`, and `checkov`, but gated behind a boolean variable (`enable_expensive_resources = false` by default). The gated resources remain toggled off during daily work or are toggled to `true` for a 30 to 60 minute window to run `terraform apply`, capture Appendix G screenshot evidence, and run `terraform destroy` with destroy verification.

Corrected Tier 3 costs:

- **Transit Gateway:** $0.05 per hour per attachment, about $36 per month per attachment, plus data processing.
- **AWS Verified Access:** $0.10 per hour per instance, plus per-user charges. Production cost is above $150 per month.
- **Interface VPC Endpoints:** $0.01 per hour per AZ. That is $7.20 per AZ per month. With 3 AZs, that is $21.60 per endpoint per month. With 5 endpoints x 3 AZs, that is $108 per month in production. Test-environment evidence uses 1 AZ, or the resource is gated to `false` and documented with Terraform + `terraform plan`.
- **Aurora Postgres:** Hourly + storage + I/O. Creation alone takes 10 to 15 minutes.
- **AWS Transfer Family SFTP:** $0.30 per hour + data.

**Destroy verification:** After `terraform destroy`, verification is via `terraform state list` (empty or only backend) + AWS console check for orphaned ENIs, snapshots, KMS pending deletion, and S3 buckets with Object Lock.

### PHASE 8: Detection, Response, and 72-Hour Breach Notification — Wave 4

**Objective:** A personal data breach is detected in minutes, affected workloads are isolated automatically, and regulator-ready 72-hour notifications are generated for the NDPC and UK ICO.

## 7. Rules — 1 Fact, 1 Name

- **1 Fact, 1 Name:** Character, Location, Count, DataClass match exactly across Inventory, Diagram, Findings, RoPA, DPIA, Tables, Appendix B, Roadmap. Auditor Ctrl+F finds the same name everywhere.
- **One fact, one file:** Glossary lives once in `docs/glossary.md`. Compliance mapping lives once in `compliance/compliance-mapping.md`. Other docs link.
- **Separation:** `00-prerequisites.md` is the operational checklist. `Foundational_Roadmap.md` is The Foundation, the story and narrative. They are separate files.
- **Audit Report name:** Security and Privacy Audit Report, or Audit Report, with no number in the name.
- **Phase vs Wave vs Section:** Phase = 0 to 10 roadmap block, 11 Phases. Wave = 1 to 5 delivery increment, 5 Waves. Section = single build unit inside a Phase, 56 Sections in this roadmap.
- **Naming:** `phase-1` format throughout. `terraform/phases/phase-1/`, `docs/phases/phase-1-...`, `evidence/sections-after/phase-1/`.
- **Email separator:** Em-dash style. `Personal Gmail: funmi.personal@gmail.com — Funmi Daniels (Sales, AE)` and `WorkMail: funmi.daniels@aftercast.ai — Funmi Daniels (Sales, AE)`.
- **Fictional Gmail disclaimer:** The disclaimer appears on: cover, note after title, full disclaimer in Sec 2.2, footnote in Sec 4 / Table 3, footer, README, Appendix B.
- **Terminology:** DataClass tags are Restricted-PII and Restricted-PII + Sensitive. SPII is not a DataClass tag. Node (7-Node model) is used consistently. Transit A-F is used. Lifecycle Phases are: Collection, Ingestion, Distribution, Access, Replication, Retention.
- **RetentionDays:** Only 90, 180, 365, 1825. Pseudonymisation is a technique.
- **Counts:** The count is 143 total = 11 hired + 132 rejected.
- **Logs vs PII:** Logs + deletion proof are kept 6 years in Glacier Deep Archive. PII is not kept 6 years. Flow 1 PII is deleted 365d. Flow 2 rejected is deleted 180d, hired is kept 6y.
- **Cost:** Test-environment cost with gating is $0 to $3 per month for most work. Production steady-state is $850 to $1,450 per month as in Business Case.
