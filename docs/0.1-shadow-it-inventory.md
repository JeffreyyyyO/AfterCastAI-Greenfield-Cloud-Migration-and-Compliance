## 2. Flow 1 - EU Customer Data Ingestion - In scope

**Flow:** LuxeMart UK (data controller) sends customer list to AfterCast AI (data processor) for forecasting.

**Data:** Name, Email, Phone, Delivery Address, Loyalty ID, Purchase History. Count: 12,000 EU. DataClass: Restricted-PII, EU.

### 2.1 Corrected 7-Node flow

| Node | Location / Owner | What happens | Gap |
| :--- | :--- | :--- | :--- |
| Box 1 Source | LuxeMart UK | Sends CSV | No secure intake enforced, no DPA forbidding WeTransfer, no SCCs documented |
| Transit A | WeTransfer link | Client sends CSV via WeTransfer, no encryption | Unsecured, no password expiry, no encryption in transit |
| Box 2 Actor 1 | Personal Gmail: funmi.personal@gmail.com — Funmi Daniels (Sales, AE) | Funmi downloads to personal laptop | Gmail is Rest Node. Laptop is device used to access, not the repository. No MDM, no disk encryption, no DLP, no corporate identity. |
| Transit B | Manual download + upload | Funmi downloads, then uploads to Dropbox | Shadow copy creation, no version control, file moves via sync with no scanning |
| Box 3 Storage 1 | Personal Dropbox: funmi.personal.dropbox.com — Funmi Daniels (Sales, AE) | Dropbox, anyone-with-link, US servers, 12,000 Restricted-PII | No DPA, no enforcement. Correction: BEFORE has no DataClass tag enforcement. DataClass tag is AFTER control. |
| Transit C | Dropbox link via WhatsApp | Link shared via WhatsApp | Public link, any recipient can forward |
| Box 4 Transmission | WhatsApp Group AfterCast Sales, 5 members + 2 ex-staff | Group chat, media auto-saves to phones | No audit trail, ex-staff unrevoked, no way to revoke for specific members |
| Transit D | Uncontrolled distribution | Link retrieved from WhatsApp, downloaded | No audit, no revoke, indefinite retention in WhatsApp history + backup |
