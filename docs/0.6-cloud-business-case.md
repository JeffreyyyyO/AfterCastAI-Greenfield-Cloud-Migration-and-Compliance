## 1. Executive Summary

AfterCast AI operates two data flows. Flow 1 is LuxeMart UK forecasting for 12,000 EU customers. Flow 2 is recruitment for 143 NG applicants and staff, 11 hired and 132 rejected.

The Before Architecture is legacy on-prem plus Shadow SaaS. It holds 13 copies of personal data and 73,001 exposure points. The Audit Report records 14 findings, 7 Critical and 7 High.

The After Architecture is an AWS Landing Zone in `eu-west-1` with `eu-west-2` as backup. It holds 2 copies of personal data, 1 per Flow, and 12,143 exposure points. The 14 findings are closed, with evidence in Appendix G + H.

Production steady-state cost is $850 to $1,450 per month. Test-environment cost with gating is $0 to $3 per month for most work. Test-environment cost and production cost are distinct.

Delivery is 11 Phases, 56 Sections, 5 Waves, 16 weeks. Each Wave has a go / no-go gate. Gate outcome: Criteria met = next Wave begins. Criteria not met = next Wave does not begin.

This file is the Business Case. It states cost, benefit, risk, and delivery. `0.0-prerequisites.md` is the operational checklist. `0.7-foundational-roadmap.md` is The Foundation, the story and narrative. `0.8-cloud-deployment-roadmap.md` is the Roadmap.

## 3. Cost Model

### 3.1 Cost Model — 3 Tiers

Test-environment cost with gating is $0 to $3 per month for most work. Production steady-state cost is $850 to $1,450 per month. Test-environment cost and production cost are distinct.

| Tier | Content | Cost |
| :--- | :--- | :--- |
| Tier 1 — Control Plane Definitions | Organizations, OUs, SCPs, Tag Policies, Identity Center, IAM Roles / Policies, Permission Boundaries, GitHub OIDC, S3 Access Points, VPCs, Subnets, Route Tables, Security Groups, S3 Gateway Endpoints, DynamoDB Gateway Endpoints, Lambda / Step Function definitions | $0.00 for the definition, Free Tier / pennies for use |
| Tier 2 — Free Tier / Pennies | S3, DynamoDB, API Gateway + Cognito, CloudWatch Logs, EventBridge, SNS, KMS ($1 per key per month, 7 to 30 day deletion waiting), GuardDuty / Macie / Security Hub 30-day trials, WorkMail 30-day trial for 25 users, Secrets Manager $0.40 per secret per month + API, no trial | $0.00 to $3.00 per month for test-environment use |
| Tier 3 — Gated Hourly | Transit Gateway $0.05 per hour per attachment, Verified Access $0.10 per hour per instance + per-user, Interface Endpoints $0.01 per hour per AZ ($7.20 per AZ per month, $21.60 per endpoint with 3 AZs), Aurora hourly + storage + I/O, Transfer Family $0.30 per hour + data | Gated by `var.enable_expensive_resources = false`, gated window 30 to 60 minutes |

Destroy verification is via `terraform state list` + AWS console check for orphaned ENIs, snapshots, KMS pending deletion, and S3 buckets with Object Lock.

## 6. Risks and Mitigations

### 10.1 Numbering System — Rules

- Phase 0 docs use `0.x`, sequential from `0.0` to `0.18`, with no gaps. `0.0` is prerequisites. `0.1` is Shadow IT Inventory. `0.2` is Audit Report. `0.3` is RoPA. `0.4` is DPIA — HR. `0.5` is DPIA — Profiling. `0.6` is this file, Business Case. `0.7` is Foundational Roadmap. `0.8` is Roadmap. `0.9` is Glossary. `0.10` is Appendix B. `0.11` is Classification. `0.12` is Retention. `0.13` is Compliance Mapping. `0.14` is DPA + TIA. `0.15` is Privacy Notice. `0.16` is Legacy Sanitization Certificate. `0.17` is Appendix G. `0.18` is Appendix H.
- Phase guides use `phase-N`, for example `phase-1-organization-identity.md`. They are not `0.x`, because they belong to Phases 1 to 10, not Phase 0.
- Evidence uses `phase-N`, for example `evidence/sections-after/phase-1/`. It is not `0.x`.
- Terraform uses `phase-N`, for example `terraform/phases/phase-1/`. It is not `0.x`.
- File names keep bare `before` / `after` where they appear: `audit-before`, `sections-after`, `0.18-appendix-h-before-vs-after.md`.

## 12. Rules — 1 Fact, 1 Name

- **1 Fact, 1 Name:** Character, Location, Count, DataClass match exactly across Inventory, Diagram, Findings, RoPA, DPIA, Tables, Appendix B, Roadmap. Auditor Ctrl+F finds the same name everywhere.
- **One fact, one file:** Glossary lives once in `0.9-glossary.md`. Compliance mapping lives once in `0.13-compliance-mapping.md`. Other docs link.
- **Separation:** `0.0-prerequisites.md` is the operational checklist. `0.7-foundational-roadmap.md` is The Foundation, the story and narrative. They are separate files.
- **Audit Report name:** Security and Privacy Audit Report, or Audit Report, with no number in the name.
- **Phase vs Wave vs Section:** Phase = 0 to 10 roadmap block, 11 Phases. Wave = 1 to 5 delivery increment, 5 Waves. Section = single build unit inside a Phase, 56 Sections in the Roadmap.
- **Naming:** `phase-1` format throughout. `terraform/phases/phase-1/`, `docs/phases/phase-1-...`, `evidence/sections-after/phase-1/`.
- **Numbering:** All doc filenames use the numbering system in Sec 10.1. Phase 0 docs use `0.x`. Phase guides, evidence, and Terraform use `phase-N`.
- **Email separator:** Em-dash style. `Personal Gmail: funmi.personal@gmail.com — Funmi Daniels (Sales, AE)` and `WorkMail: funmi.daniels@aftercast.ai — Funmi Daniels (Sales, AE)`.
- **Fictional Gmail disclaimer:** The disclaimer appears on: cover, note after title, full disclaimer in Sec 2.2, footnote in Sec 4 / Table 3, footer, README, Appendix B.
